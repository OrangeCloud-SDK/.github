## 🎯 产品导航

### 💬 [IM SDK — 即时通信](https://github.com/OrangeCloud-SDK-IM)

为直播间、社交、协作场景提供实时消息能力。

| 特性 | 说明 |
|------|------|
| 🚀 毫秒级送达 | 基于 SignalR 长连接 |
| 📱 全平台 | Flutter / iOS / Android / Web |
| 🔄 自动重连 | 指数退避 + 断线消息补发 |
| 🎁 丰富消息 | 文本、礼物、弹幕、公告、自定义 |
| 🔒 安全鉴权 | HMAC-SHA256 + 域名白名单 |

**👉 [前往 IM SDK](https://github.com/OrangeCloud-SDK-IM)**

---

### 🎬 [Player SDK — 视频播放器](https://github.com/OrangeCloud-SDK-Player)

企业级跨平台视频播放器，支持点播/直播全场景。

| 特性 | 说明 |
|------|------|
| 🎥 全格式 | HLS / DASH / MP4 / FLV |
| 🔐 DRM 加密 | Widevine / FairPlay |
| ⚡ 短视频模式 | 上下滑动、预加载、播放池 |
| 📥 离线下载 | 后台下载、断点续传 |

**👉 [前往 Player SDK](https://github.com/OrangeCloud-SDK-Player)**

---

### 💄 Beauty SDK — AI美颜

AI 驱动的实时美颜 SDK，支持美白磨皮、面部重塑、滤镜贴纸、美妆。

| 特性 | 说明 |
|------|------|
| 🎨 基础美颜 | 美白、磨皮、红润、锐化 |
| 👤 面部重塑 | 瘦脸、大眼、瘦鼻、下巴 |
| 🖼️ 滤镜 | LUT 滤镜、哈哈镜变形 |
| 💄 美妆 | 口红、腮红、眉毛、眼影 |
| 🎭 贴纸 | 2D/3D 人脸贴纸 |
| 📊 性能监控 | GPU/CPU 帧率实时统计 |

| 平台 | 仓库 |
|:---:|------|
| 🐦 Flutter | [orangecloud-beauty-flutter](https://github.com/OrangeCloud-SDK/orangecloud-beauty-flutter) |
| 🍎 iOS | [orangecloud-beauty-ios](https://github.com/OrangeCloud-SDK/orangecloud-beauty-ios) |
| 🤖 Android | [orangecloud-beauty-android](https://github.com/OrangeCloud-SDK/orangecloud-beauty-android) |
