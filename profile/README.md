## 🎯 产品导航

### 💬 [IM SDK — 即时通信](https://github.com/OrangeCloud-SDK-IM)

为直播间、社交、协作场景提供实时消息能力。

| 特性 | 说明 |
|------|------|
| 🚀 毫秒级送达 | 基于 SignalR 长连接 |
| 📱 全平台 | Flutter / iOS / Android / Web |
| 🔄 自动重连 | 指数退避 + 断线消息补发 |
| 🎁 丰富消息 | 文本、礼物、弹幕、公告、自定义 |
| 🔒 安全鉴权 | HMAC-SHA256 + 域名白名单 |
| 📊 套餐计费 | 免费版起步，按 DAU 计费 |

**👉 [前往 IM SDK 组织](https://github.com/OrangeCloud-SDK-IM)**

### 🎬 [Player SDK — 视频播放器](https://github.com/OrangeCloud-SDK-Player)

企业级跨平台视频播放器，支持点播/直播全场景。

| 特性 | 说明 |
|------|------|
| 🎥 全格式 | HLS / DASH / MP4 / FLV |
| 🔐 DRM 加密 | Widevine / FairPlay |
| 📝 多字幕 | SRT / VTT / ASS |
| 📺 画中画 | iOS / Android PiP |
| ⚡ 短视频模式 | 上下滑动、预加载、播放池 |
| 📥 离线下载 | 后台下载、断点续传 |

**👉 [前往 Player SDK 组织](https://github.com/OrangeCloud-SDK-Player)**
